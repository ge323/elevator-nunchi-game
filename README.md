# 엘베 눈치게임

퇴근길 엘리베이터에서 닫힘 버튼을 연타해 상사를 따돌리는 한 손 모바일 웹 게임입니다.
일반 승객과 상사를 구분하는 눈치, 랜덤 상황, 엔딩 도감, 승진과 환생 시스템이 들어 있습니다.

## 바로 해보기 (설치 없음)

`index.html`을 브라우저로 열면 바로 실행됩니다. 서버나 빌드 과정이 필요 없습니다.

## GitHub Pages로 공개하기

1. 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Branch**를 `main`, 폴더를 `/ (root)`로 선택하고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소로 접속할 수 있습니다.

이 주소를 친구에게 보내면 됩니다. 게임 안의 "친구에게 자랑하기" 버튼은 현재 접속 중인 주소를 자동으로 사용합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 (시작, 게임, 결과, 상점, 도감, 일기 등) |
| `style.css` | 스타일과 내장 폰트 |
| `game.js` | 게임 로직, 그림 그리기, 저장 |

## 미션과 업적

- **일일 미션**: 매일 3개가 날짜에 따라 정해지고, 달성하면 코인을 받습니다. 3개를 모두 받으면 추가 보너스가 있습니다.
- **업적**: 누적 기록(일반 승객 수, 탭 횟수, 최고 층 등)에 따라 코인이나 캐릭터 의상을 줍니다.
- 미션 후보는 `DQ`, 업적은 `AC`, 의상은 `SK` 배열에서 고칠 수 있습니다.

## 기록 저장

- 코인, 직급, 도감 등은 브라우저의 `localStorage`(키: `elv_w`)에 저장됩니다.
- 브라우저 데이터를 지우거나, 다른 기기와 브라우저로 접속하면 기록이 보이지 않습니다.
- 서버나 계정 연동은 아직 없습니다.

- **백업 코드**: 강화 상점의 "기록 백업 코드 복사"로 기록을 문자열로 저장하고, "기록 불러오기"로 다른 기기나 새 주소에서 복원할 수 있습니다. 코드는 간단한 검증값이 붙어 있지만 조작을 완전히 막지는 못합니다. 랭킹 기능을 만들 때는 서버 검증이 필요합니다.

## 자주 바꾸는 값 (game.js)

- 난이도: `newRound()` 안의 `const d=Math.max(1.3,4-.15*score);`
- 승진 비용: `RC`, 환생 복귀 비용: `JC`
- 엔딩과 일기 문구: `ENDS`, `DIA`
- 이어서 하기 비용: `rvc`
- 층별 배경: `TH`, `THN`

## 폰트와 라이선스

- 게임 글꼴은 **Limgul Mono 14**를 게임에 쓰는 글자만 남겨 `style.css`에 내장한 것입니다.
- **저장소를 공개하기 전에 폰트 배포처의 라이선스를 꼭 확인하세요.** 재배포나 앱 포함, 상업적 이용이 가능한지 폰트마다 다릅니다.
- 문제가 있다면 `style.css` 맨 앞의 `@font-face` 두 줄을 지우면 기본 글꼴로 돌아갑니다.
- 이 저장소에는 아직 코드 라이선스 파일이 없습니다. 공개 범위에 맞게 직접 추가하세요.
